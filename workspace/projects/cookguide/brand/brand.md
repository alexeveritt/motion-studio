# CookGuide brand

> Placeholder guidance for the acceptance production. **To confirm** with the owner.

## Logo usage

- Use `brand:placeholder-logo-mark.svg` (placeholder) with the word "CookGuide" set in Inter ExtraBold.
- Never place the logo over or touching a QR code.

## Colours

| Name       | Hex     | Use                         |
| ---------- | ------- | --------------------------- |
| Cream      | #FFF6E9 | Backgrounds                 |
| Herb green | #2E7D4F | Primary brand colour        |
| Tomato     | #E4572E | Accents and highlights only |
| Ink        | #1D1B16 | Text                        |

## Typography

Inter (SIL Open Font License 1.1), stored as brand assets: Regular 400, SemiBold 600 and ExtraBold 800.

## Imagery

Warm, real kitchens and food. No stock imagery with unverified licences.

## QR codes

Black on white, at least a four-module quiet zone, no logo inside the code, nothing overlapping it, and static whenever it is on screen for scanning.
